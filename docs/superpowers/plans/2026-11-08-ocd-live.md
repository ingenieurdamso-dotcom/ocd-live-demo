# OCD Live Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Exécution autonome approuvée, sans dépôt ni git.

**Goal:** Construire une démonstration PWA complète, française, réservation et administration, clairement proposée par Adama et non officielle.

**Architecture:** React/Vite sert une interface adaptative ; Express et SQLite local sont la source de vérité transactionnelle. Les secrets et la base restent hors des fichiers publics et hors archive. Les demandes utilisent des liens à jeton aléatoire et les opérations administratives une session serveur.

**Tech Stack:** Node 24, SQLite intégré, Express 5, React, TypeScript, Vite, tests node:test + React rendu serveur.

## Global Constraints
- Nouveau dossier autonome /workspace/ocd-live ; aucun dépôt existant, clone, commit, déploiement ou compte externe.
- Démonstration Adama non officielle, données fictives uniquement, six packs illustratifs en FCFA non validés, aucun paiement/envoi externe.
- Fuseau Lomé et Ouagadougou UTC+0 ; ouverture tous les jours 09:00–21:00, horizon 90 jours, départs toutes les 30 min, une ressource, aucun tampon implicite.
- Options et propositions 24h ; intervalles semi-ouverts ; expiration contrôlée sur lectures/écritures ; aucune action hors ligne.
- Mensuel = crédit de quatre sessions de 90 min, première réservée, trois planifications manuelles ultérieures non réservées ni vendues réellement.
- Logo exact fourni séparément à intégrer ; pas de logo inventé. Superdesign auth indisponible, design approuvé exécuté localement sans brouillon externe.
